# 子串 | Substring · 滑动窗口

!!! abstract "Hot 20 · 第 4 类"
    **什么时候想到它**：题目问「**连续**子串 / 子数组」满足某种条件——最长、最短、包含某些字符、不含重复。
    **核心动作**：右指针负责扩张，左指针负责在不合法时收缩，窗口内永远维护一个**能 O(1) 判定**的状态。

## 套路

1. 先明确**合法判据**，并且能增量维护：计数达标（76）、窗口内无重复（3）、和不超过 k。
2. 右扩：把 `s[right]` 纳入窗口，更新判据。
3. 左缩：`while 条件成立: 记录答案 → 把 s[left] 移出 → left += 1`。
4. 每个字符最多进出各一次，总共 $O(|s|)$，不会退化成「枚举所有子串」。

「最短」和「最长」的写法不同：

| 目标 | 收缩时机 | 记录时机 |
|:-----|:---------|:---------|
| 最短覆盖子串（76） | 一合法就收缩 | **收缩过程中**记录最短 |
| 最长无重复（3） | 一出现重复就收缩 | **收缩完成之后**记录 |

## 易错点

- 判据别每次重算：76 用「达标种数」，3 用「窗口内出现次数」，重算就退化成 $O(n^2)$。
- **先记录再移左指针**，顺序反了会少算一格。
- 定长窗口（567/438）进出要成对：进一个就必须出一个。
