最小覆盖子串 · 滑动窗口动画

LeetCode 76：在 s = "ADOBECODEBANC" 里找最短的、涵盖 t = "ABC" 全部字符的子串。

算法只有一句话：右指针负责凑齐（扩张），凑齐后左指针负责尽量多扔（收缩）。每次窗口刚好覆盖 t 时记一次长度，最短的那个就是答案。用 formed 记「已经有几种字符的配额刚好齐了」，formed == required 即窗口合法，于是「是否覆盖」的判定是 O(1) 的。

复杂度O(m+n)

        
时间 O(m + n)：右指针把 s 扫一遍，左指针也只前进不后退，每个字符进出窗口各一次。

        
空间 O(1)（字符集大小）：两个定长计数数组，与 m、n 无关。
