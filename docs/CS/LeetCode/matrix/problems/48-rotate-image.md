# 48. 旋转图像

!!! abstract "题单坐标"
    **Hot 20 · 第 5 类「矩阵」** ｜ 难度：中等 ｜ 标签：`数组` `矩阵` `数学`

    一句话套路：顺时针 90° 拆成「沿主对角线转置」再「每一行左右翻转」，两次都是原地交换。

## 题干

> [力扣 48. 旋转图像](https://leetcode.cn/problems/rotate-image/)

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像，请你将图像顺时针旋转 90 度。

你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要**使用另一个矩阵来旋转图像。

**示例 1**

```text
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2**

```text
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**提示**

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 思路

设原矩阵为 $a$，顺时针转 90° 后 $b[i][j] = a[n-1-j][i]$。例如 $n = 3$ 时，位置 `(0,1)` 的 2 应该去 `(1,2)`：行号变成原来的列号，列号变成 `n-1-原行号`。

原地不能先读后写一整圈，否则会把还没读的格子盖掉。把它拆成两个对合（做两次等于没做）的操作：

1. **转置**：$a[i][j] \leftrightarrow a[j][i]$，只遍历 $j > i$。转完之后，$a[i][j]$ 里放的是原来的 $a[j][i]$。
2. **行翻转**：$a[i][j] \leftrightarrow a[i][n-1-j]$。转置后的第 $i$ 行再左右反过来，就得到 $a_{\text{转置}}[i][n-1-j] = a[n-1-j][i]$，正好是 $b[i][j]$。

逆时针是同一套公式的另一侧：$b[i][j] = a[j][n-1-i]$，也就是转置之后按列翻转。

**走一遍示例。** `[[1,2,3],[4,5,6],[7,8,9]]`。

转置，只交换上三角的三对 `(0,1)(0,2)(1,2)`：

```text
1 2 3        1 4 7
4 5 6   →    2 5 8
7 8 9        3 6 9
```

每行反转：

```text
1 4 7        7 4 1
2 5 8   →    8 5 2
3 6 9        9 6 3
```

中心的 5 两次都不动。

## 代码（带注释）

> 按力扣提交格式写：一个 `Solution` 类。题目要求原地修改，返回值是 `None`。

=== "主推：转置 + 行翻转"

    ```python
    class Solution:
        def rotate(self, matrix: list[list[int]]) -> None:
            n = len(matrix)
            for i in range(n):
                for j in range(i + 1, n):
                    matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
            for row in matrix:
                row.reverse()
    ```

    `j` 从 `i + 1` 开始，主对角线和已经交换过的下三角不会再碰。`n = 1` 时两层循环都不进，矩阵保持不变。

=== "对照：四格轮换"

    ```python
    class Solution:
        def rotate(self, matrix: list[list[int]]) -> None:
            n = len(matrix)
            for i in range(n // 2):
                for j in range(i, n - 1 - i):
                    tmp = matrix[i][j]
                    matrix[i][j] = matrix[n - 1 - j][i]
                    matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j]
                    matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i]
                    matrix[j][n - 1 - i] = tmp
    ```

    一层一层、每四个位置转一圈。`j` 的右端是 `n-1-i`，不能写成 `n`，否则角上的格子会被转两次。面试里转置版更不容易写错下标。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| 转置 + 翻转 | $O(n^2)$ | $O(1)$ | 默认 |
| 四格轮换 | $O(n^2)$ | $O(1)$ | 想强调「每个格子恰好搬一次」时 |
| 新开矩阵按公式填 | $O(n^2)$ | $O(n^2)$ | 题目不允许，只用来推导公式 |

$n \le 20$，两种原地写法都只碰每个格子常数次。额外空间是交换用的一个临时变量。

## 易错点

- **转置写成 `j` 从 0 到 `n`**：下三角再交换一次，矩阵转回去了。
- **先翻转再转置**：`[[1,2,3],[4,5,6],[7,8,9]]` 会得到 `[[3,6,9],[2,5,8],[1,4,7]]`，那是逆时针。
- **四格轮换的内层右边界写成 `n`**：角点 `(0,n-1)` 被转两次，结果错一位。
- **用另一个矩阵「先算好再拷回来」**：能得到正确数字，但不符合原地要求，空间也变成 $O(n^2)$。
