# 矩阵 | Matrix

!!! abstract "Hot 20 · 第 5 类"
    **什么时候想到它**：二维数组要原地改、按层处理，或者下标之间有 `i ↔ j`、`n-1-j` 这种对称。
    **核心动作**：先写出目标位置的公式，再把它拆成两次原地对称（转置、翻转），避免开第二块矩阵。

## 套路

顺时针转 90° 的新位置是 $b[j][n-1-i] = a[i][j]$，等价写法 $b[i][j] = a[n-1-j][i]$。直接按这个公式写需要一块新矩阵。原地做法拆成两步，每一步都是自己和自己交换，不会互相覆盖：

1. 沿主对角线转置：只走 $i < j$，`a[i][j] ↔ a[j][i]`。
2. 每一行左右翻转：`a[i][j] ↔ a[i][n-1-j]`。

逆时针则是转置之后按列翻转。四格一组轮换（`(i,j) → (j,n-1-i) → ...`）也能原地做，层数是 $n//2$，但下标更容易写反。

## 易错点

- 转置时把下三角也交换一遍，等于交换了两次，矩阵回到原样。
- 先翻转再转置，得到的是逆时针，不是顺时针。
- `n` 是奇数时中心格不参与任何交换，不要为它写特判。
