# 1143. 最长公共子序列

!!! abstract "题单坐标"
    **Hot 20 · 第 14 类「多维动态规划」** ｜ 难度：中等 ｜ 标签：`字符串` `动态规划`

    一句话套路：`dp[i][j]` 是 `text1` 前 `i` 个和 `text2` 前 `j` 个的最长公共子序列长度。末字符相等就从左上加一，否则从「丢掉 text1 末字符」和「丢掉 text2 末字符」里取大。

## 题干

> [力扣 1143. 最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长公共子序列的长度。如果不存在公共子序列，返回 `0`。

一个字符串的子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的公共子序列是这两个字符串所共同拥有的子序列。

**示例 1**

```text
输入：text1 = "abcde", text2 = "ace"
输出：3
解释：最长公共子序列是 "ace"，它的长度为 3。
```

**示例 2**

```text
输入：text1 = "abc", text2 = "abc"
输出：3
```

**示例 3**

```text
输入：text1 = "abc", text2 = "def"
输出：0
```

**提示**

- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字符组成

## 思路

`dp[i][j]` 的含义先定死：只用 `text1[:i]` 和 `text2[:j]`（都不含下标 `i`、`j` 本身，也就是前 `i` / 前 `j` 个字符）时的 LCS 长度。

看两个前缀的最后一个字符 `text1[i-1]` 和 `text2[j-1]`：

- 相等：这个字符一定可以接在 `dp[i-1][j-1]` 后面，`dp[i][j] = dp[i-1][j-1] + 1`。它不会比丢掉任一端更差，所以不用再和另外两个方向比。
- 不相等：最后一个字符至少有一个不在这条公共子序列里。丢掉 `text1` 的末字符是 `dp[i-1][j]`，丢掉 `text2` 的末字符是 `dp[i][j-1]`，取较大的那个。

边界：空串和任何串的 LCS 都是 0，所以第 0 行、第 0 列保持 0。填表时 `i`、`j` 都从小到大，因为每个格子只依赖左、上、左上，这三个都已经算过。

**走一遍 `"abcde"` 和 `"ace"`。** 行是 `text1`，列是 `text2`。

|  | ε | a | c | e |
|:--|:--|:--|:--|:--|
| ε | 0 | 0 | 0 | 0 |
| a | 0 | 1 | 1 | 1 |
| b | 0 | 1 | 1 | 1 |
| c | 0 | 1 | 2 | 2 |
| d | 0 | 1 | 2 | 2 |
| e | 0 | 1 | 2 | 3 |

`(1,1)` 两个 `a` 相等，左上 0 加 1。`(3,2)` 两个 `c` 相等，左上 1 加 1。`(5,3)` 两个 `e` 相等，左上 2 加 1，得到 3。`b` 和 `d` 所在的行只能从上面或左边抄。

## 代码（带注释）

> 按力扣提交格式写：一个 `Solution` 类。只用内置类型。

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i - 1] == text2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        return dp[m][n]
```

两层循环各走一遍字符串，每个格子 $O(1)$。想把序列本身打印出来，就从 `(m, n)` 往回看：相等则收下这个字符并走向左上，否则走向较大的那一侧。

滚动数组可以把空间压成两行甚至一行，但一行时左上角会被本行的新值盖掉，要额外存 `prev`。长度题先写完整二维表。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| 二维 dp | $O(mn)$ | $O(mn)$ | 默认 |
| 滚动两行 | $O(mn)$ | $O(\min(m,n))$ | 只要长度、想省空间 |
| 暴力枚举子序列 | $O(2^{m+n})$ | $O(m+n)$ | 只用来说明不能这么做 |

两条字符串都到 1000，$O(mn)$ 是 $10^6$ 个格子，能过。

## 易错点

- **下标差一位**：`dp` 有第 0 行第 0 列，比较的是 `text1[i-1]` 不是 `text1[i]`。写成 `text1[i]` 会在最后一格越界。
- **相等时还去 `max` 三个方向**：加上左、上之后可能把同一个字符用两次，长度偏大。相等时只取左上加一。
- **子序列写成子串**：子串必须连续，那是另一题（最长公共子串）。`"ace"` 在 `"abcde"` 里不连续，但本题算数。
- **答案取错格子**：要的是 `dp[m][n]`。中途出现过的较大值如果没能延续到两个前缀的末尾，不会比右下角更大——右下角已经考虑过丢掉末尾字符。
