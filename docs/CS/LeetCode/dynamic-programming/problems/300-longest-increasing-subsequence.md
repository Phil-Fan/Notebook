# 300. 最长递增子序列

!!! abstract "题单坐标"
    **Hot 20 · 第 14 类「多维动态规划」里的一维特例** ｜ 难度：中等 ｜ 标签：`数组` `二分查找` `动态规划`

    一句话套路：`dp[i]` 是以 `nums[i]` 结尾的最长递增子序列长度；要 $O(n \log n)$ 就改成维护 `tails`，二分找第一个不小于当前数的位置。

## 题干

> [力扣 300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

给你一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如 `[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

**示例 1**

```text
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4。
```

**示例 2**

```text
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3**

```text
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示**

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

进阶：你能将算法的时间复杂度降低到 $O(n \log n)$ 吗？

## 思路

子序列不必连续，但相对顺序要保留。

**$O(n^2)$：以 i 结尾。** `dp[i]` 表示以 `nums[i]` 结尾的最长严格递增子序列长度。转移：

$$dp[i] = 1 + \max\{dp[j] \mid j < i,\ nums[j] < nums[i]\}$$

没有这样的 `j` 时，`dp[i] = 1`，这个数单独成一段。答案是所有 `dp[i]` 的最大值，不是 `dp[n-1]`：最长的那段不一定以最后一个数结尾。示例 1 里 18 结尾的长度是 4，101 结尾的也是 4，但若数组在 101 处截断，答案仍然是 4，而最后一个位置的 dp 不能代表全局。

**$O(n \log n)$：tails。** `tails[len]` 表示「长度为 `len+1` 的递增子序列里，结尾最小能是多少」。它单调不降。读到 `x` 时，二分找第一个 `tails[i] >= x`：

- 找到了：用 `x` 替换它。同样长度的子序列，结尾改得更小，后面更容易接上。
- 没找到：`x` 比所有结尾都大，接在最后，长度加一。

`tails` 的长度就是答案。它**不是**那条子序列本身：替换会打断下标对应关系。示例 1 结束时 `tails = [2,3,7,18]`，18 是替换 101 的结果，真正的一条子序列可以是 `[2,3,7,101]`。

**走一遍示例 1 的 tails。**

| x | tails | 动作 |
|:--|:------|:-----|
| 10 | `[10]` | 空，追加 |
| 9 | `[9]` | 替换 10 |
| 2 | `[2]` | 替换 9 |
| 5 | `[2,5]` | 比 2 大，追加 |
| 3 | `[2,3]` | 替换 5 |
| 7 | `[2,3,7]` | 追加 |
| 101 | `[2,3,7,101]` | 追加 |
| 18 | `[2,3,7,18]` | 替换 101 |

长度为 4。

## 代码（带注释）

> 按力扣提交格式写：一个 `Solution` 类。只用内置类型。

=== "主推：tails + 二分"

    ```python
    class Solution:
        def lengthOfLIS(self, nums: list[int]) -> int:
            tails: list[int] = []
            for value in nums:
                lo, hi = 0, len(tails)
                while lo < hi:
                    mid = (lo + hi) // 2
                    if tails[mid] < value:
                        lo = mid + 1
                    else:
                        hi = mid
                if lo == len(tails):
                    tails.append(value)
                else:
                    tails[lo] = value
            return len(tails)
    ```

    `lo` 是第一个大于等于 `value` 的位置。严格递增所以等于也要替换：两个 7 不能接在一起，第二个 7 应占据「长度 1」那个槽，而不是追加。

=== "对照：以 i 结尾的 dp"

    ```python
    class Solution:
        def lengthOfLIS(self, nums: list[int]) -> int:
            dp = [1] * len(nums)
            for i in range(len(nums)):
                for j in range(i):
                    if nums[j] < nums[i]:
                        dp[i] = max(dp[i], dp[j] + 1)
            return max(dp)
    ```

    好写，也方便顺着 `dp` 把子序列本身回溯出来。`n = 2500` 时 $O(n^2)$ 大约是 $6 \times 10^6$ 次比较，能过；进阶要求的是上面那一版。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| tails + 二分 | $O(n \log n)$ | $O(n)$ | 默认 |
| `dp[i]` | $O(n^2)$ | $O(n)$ | 要输出具体序列，或先把状态讲清楚 |
| 排序后当 LCS | $O(n^2)$ | $O(n)$ | 能做，但去重和稳定性容易写错，不推荐 |

二分每次 $O(\log n)$，共 `n` 次。`tails` 最长是 `n`。

## 易错点

- **答案取 `dp[-1]`**：最长子序列不一定以最后一个元素结尾。`[1,3,2]` 的 `dp` 是 `[1,2,2]`，取最后一个碰巧对；`[1,3,2,0]` 的最后一个 dp 是 1，答案是 2。
- **`tails` 当成真实子序列输出**：替换之后下标不再对应原数组里的一条链。题目只问长度，不要把 `tails` 当答案序列交上去。
- **二分用 `<` 还是 `<=`**：严格递增时，等于当前值的 `tails[i]` 也要被替换，所以找的是第一个 `>= value`。写成 `>` 会把相等的数追加到后面，`[7,7]` 的长度会变成 2。
- **非严格递增误用这套代码**：如果题目改成「非降」，相等时应该追加（找第一个 `>`）。两题的二分方向差在等号上。
