# 20. 有效的括号

!!! abstract "题单坐标"
    **Hot 20 · 第 10 类「栈」** ｜ 难度：简单 ｜ 标签：`栈` `字符串`

    一句话套路：左括号入栈，右括号必须和栈顶配对，配对成功就弹出；扫完之后栈必须是空的。

## 题干

> [力扣 20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s`，判断字符串是否有效。

有效字符串需满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

**示例 1**

```text
输入：s = "()"
输出：true
```

**示例 2**

```text
输入：s = "()[]{}"
输出：true
```

**示例 3**

```text
输入：s = "(]"
输出：false
```

**示例 4**

```text
输入：s = "([])"
输出：true
```

**提示**

- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 思路

括号的闭合顺序是后进先出：最里面的一对先闭合。栈里只放还没配上的左括号。

从左到右看每个字符：

- 左括号：压栈，它在等一个右括号。
- 右括号：栈空，或者栈顶不是它要的那种左括号，直接失败；否则弹出栈顶，这一对闭合。

循环结束时栈里还有左括号，说明有人没等到右括号，也失败。三种失败对应三种不合法：

| 字符串 | 失败位置 | 原因 |
|:-------|:---------|:-----|
| `(]` | 第二个字符 | 栈顶是 `(`，等的不是 `]` |
| `([)]` | 第三个字符 | 栈顶是 `[`，`]` 还没来，`)` 先到了 |
| `(()` | 扫完 | 栈里剩一个 `(` |
| `)` | 第一个字符 | 栈是空的，右括号没有可配的左括号 |

`([])` 的过程是：`(` 入栈，`[` 入栈，`]` 弹出 `[`，`)` 弹出 `(`，栈空，有效。

用右括号当键、左括号当值：`{')': '(', ']': '[', '}': '{'}`。遇到不在这张表里的字符就是左括号。这样分支不用写六次。

## 代码（带注释）

> 按力扣提交格式写：一个 `Solution` 类。只用内置类型。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        pair = {")": "(", "]": "[", "}": "{"}
        stack: list[str] = []
        for ch in s:
            if ch not in pair:
                stack.append(ch)
            elif not stack or stack[-1] != pair[ch]:
                return False
            else:
                stack.pop()
        return not stack
```

`not stack` 要写在 `stack[-1]` 之前，否则空栈上取栈顶会抛异常。最后 `return not stack` 同时覆盖「刚好配平」和「左括号多余」。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| 栈 | $O(n)$ | $O(n)$ | 默认。最坏是一长串左括号 |
| 计数器（只有一种括号） | $O(n)$ | $O(1)$ | 字符串里只有 `()` 时可以，三种括号不行 |

$n$ 到 $10^4$，线性扫描足够。三种括号嵌套时，计数器分不清 `([)]`：左右数量都平衡，但交叉了。

## 易错点

- **只判断数量相等**：`([)]` 的三种括号个数都对，但交叉闭合，栈顶对不上。
- **右括号入栈、左括号去配**：顺序反了，`()` 会在第一个字符就失败。
- **忘了最后检查栈空**：`(()` 中途每次都能配对到栈顶，但扫完还剩一个左括号。
- **空栈直接 `stack[-1]`**：以右括号开头时会异常，题目里这是 `false` 不是报错。
- **配对表的键值写反**：用左括号去查右括号，`stack[-1] != pair[ch]` 永远在比两种左括号。
