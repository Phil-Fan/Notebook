# 49. 字母异位词分组

!!! abstract "题单坐标"
    **Hot 20 · 第 1 类「哈希」** ｜ 难度：中等 ｜ 标签：`数组` `哈希表` `字符串` `排序`

    一句话套路：给每个词造一个只依赖字母构成的**规范形**（canonical form）当哈希键，同键即同组。

## 题干

> [力扣 49. 字母异位词分组](https://leetcode.cn/problems/group-anagrams/)

给你一个字符串数组 `strs`，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。

字母异位词 是由重新排列源单词的所有字母得到的一个新单词。

**示例 1**

```text
输入：strs = ["eat","tea","tan","ate","nat","bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]
```

**示例 2**

```text
输入：strs = [""]
输出：[[""]]
```

**示例 3**

```text
输入：strs = ["a"]
输出：[["a"]]
```

**提示**

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` 仅包含小写字母

## 思路

**为什么这样做对。** 「互为异位词」是 `strs` 上的等价关系（自反、对称、传递）。等价关系有一个很好用的性质：只要能写出一个**规范形**——同一等价类里所有元素得到同一个值、不同等价类得到不同值——就可以直接拿它当哈希键，分组退化成「按键入桶」，正确性是构造出来的，一次两两比较都不需要做。

于是问题变成：怎么给一个词造规范形？想到的候选都要过一遍「同键 ⇔ 同组」这两条：

| 候选键 | 无碰撞？ | 结论 |
|:-------|:---------|:-----|
| 首字母 | 否，`"ab"` 与 `"aa"` 同首字母却不同组 | 不能用 |
| 词长 | 否，`"ab"` 与 `"aa"` 同长也不同组 | 不能用 |
| 排序后的串 `"".join(sorted(w))` | 是，异位词排序后必相同 | 主推，最好写 |
| 26 维计数元组 `tuple(counts)` | 是，等价于「每种字母次数相同」 | 建键 $O(k)$，面试首选 |
| 质数乘积 `Π prime[ch]` | 是，靠唯一分解定理 | 能做但不划算，见复杂度 |

**怎么做（三步一循环）。**

1. **算签名**：对每个词 `w` 求出规范形，例如 `"eat" → "aet"`。
2. **查表**：拿签名去哈希表里查。命中说明前面出现过同组词，直接追加；未命中就新建一个桶。
3. **入桶**：把 `w` 追加进该签名对应的列表。所有词走完，哈希表里每个桶就是一组答案。

Python 的 `dict` 保序，所以组间顺序天然是「该组第一个词在 `strs` 里出现的顺序」，组内顺序就是原数组顺序——正好满足「顺序不限」。

**走一遍示例**（排序键，`strs = ["eat","tea","tan","ate","nat","bat"]`）：

| 处理 | 签名 | 动作 | 桶的状态（按首次出现序） |
|:-----|:-----|:-----|:-----------------------|
| `"eat"` | `"aet"` | 新键，建桶 | `{"aet": ["eat"]}` |
| `"tea"` | `"aet"` | 命中，追加 | `{"aet": ["eat","tea"]}` |
| `"tan"` | `"ant"` | 新键，建桶 | `{"aet": [...], "ant": ["tan"]}` |
| `"ate"` | `"aet"` | 命中，追加 | `{"aet": ["eat","tea","ate"], "ant": ["tan"]}` |
| `"nat"` | `"ant"` | 命中，追加 | `{"aet": [...], "ant": ["tan","nat"]}` |
| `"bat"` | `"abt"` | 新键，建桶 | 再多一组 `["bat"]` |

六个词只扫一遍，没有一次两两比较；「同组」这件事完全由签名相等推出。

## 代码（带注释）

> LeetCode 提交时把函数包进 `class Solution` 即可；下面的代码都能在本地直接跑。

=== "主推：排序键（最短最稳）"

    ```python
    def group_anagrams(strs: list[str]) -> list[list[str]]:
        """排序键：异位词排序后必相同（"eat"/"tea"/"ate" → "aet"）。"""
        buckets: dict[str, list[str]] = {}            # 签名 → 单词列表
        for w in strs:                                # 逐个词独立处理：一次签名 + 一次哈希
            key = "".join(sorted(w))                  # ① 算签名
            buckets.setdefault(key, []).append(w)     # ② 查表 + ③ 入桶
        return list(buckets.values())                 # dict 保序：组序 = 首词出现序
    ```

    每个词只排序一次，代价 $O(k\log k)$；`setdefault` 一行干完「查表 + 新建桶 + 追加」三件事，最不容易写错。

=== "O(k) 计数键（面试首选）"

    ```python
    def group_anagrams(strs: list[str]) -> list[list[str]]:
        """26 维计数键：异位词 ⇔ 每种字母出现次数相同。建键 O(k)，不排序。"""
        buckets: dict[tuple[int, ...], list[str]] = {}    # 键 = 26 维计数元组，值 = 同组单词列表
        for w in strs:                                    # 逐个词建签名、入桶
            counts = [0] * 26                             # 26 个小写字母各自的出现次数
            for ch in w:                                  # 扫一遍这个词，统计每种字母
                if not "a" <= ch <= "z":
                    raise ValueError(f"计数键只支持小写字母，收到 {ch!r}")  # 越界字符会静默错组，显式报错
                counts[ord(ch) - ord("a")] += 1           # 字母映射到 0~25 的下标再计数
            buckets.setdefault(tuple(counts), []).append(w)   # list 不可哈希，tuple 才行
        return list(buckets.values())                     # 取所有桶的内容作为答案
    ```

    键换成「每种字母出现几次」，建键降到 $O(k)$，代价是键固定 26 个整数。题目约束只有小写字母，所以这版最稳；遇到别的字符我让它显式报错，而不是悄悄归错组。

=== "通用：稀疏计数键（不限字符集）"

    ```python
    from collections import Counter

    def group_anagrams(strs: list[str]) -> list[list[str]]:
        """稀疏计数键：只记出现过的字母，不限字符集（Unicode 也能分组）。"""
        buckets: dict[tuple[tuple[str, int], ...], list[str]] = {}  # 键 = 排好序的 (字符, 次数) 元组
        for w in strs:                                             # 逐个词算签名、入桶
            key = tuple(sorted(Counter(w).items()))                # ① 统计后排序，保证顺序无关；② 转 tuple 才能当键
            buckets.setdefault(key, []).append(w)                  # ③ 入桶
        return list(buckets.values())                              # 取所有桶的内容作为答案
    ```

    键长是「词内不同字母数 $d$」而不是 26，短词、大小写混排、甚至中文都能分组；`sorted` 不能省，否则 `("a",1),("b",1)` 和 `("b",1),("a",1)` 会变成两个不同的键。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| 排序键 | $O(nk\log k)$ | $O(nk)$ | 默认、最好写、最好讲 |
| 26 维计数键 | $O(\Sigma + 26n)$ | $O(26n)$ | 限定小写字母、想压常数 |
| 稀疏计数键 | $O(\Sigma + nd\log d)$ | $O(nd)$ | 字符集不确定、词很短 |
| 质数乘积键 | $O(\Sigma)$ + 大整数乘法 | $O(nk)$ | 只适合讲数学，不推荐 |

其中 $n$ 是词数，$k$ 是词长，$\Sigma$ 是字符总数，$d$ 是词内不同字母数，$O(26n)$ 里 26 当常数看。LeetCode 49 约束 $n$ 最多 10⁴、$k$ 最多 100、只有小写字母，三种写法都过。质数乘积键在 Python 里靠大整数不会溢出，但词长 100 时乘积已有 500+ bit，乘法和哈希都比计数键慢，不值得。

## 易错点

- **拿首字母或词长当键**：`"ab"` 与 `"aa"` 首字母相同、长度也相同，却不是异位词；这两类键都无法反推「每种字母各几个」。键必须对字母构成单射。
- **把 `counts` 这个 list 直接当字典键**：会抛 `TypeError: unhashable type: 'list'`。`list` 和 `dict` 不可哈希，必须 `tuple(counts)`；而 tuple 一旦生成就不能再改，所以要先把计数算完再转。
- **计数键套用到非小写字母上**：`ord(ch) - ord("a")` 对 `"A"` 得 -1、对 `"中"` 得几万，写出来的下标越界或为负，会把不同词静默归到同一个桶，答案错了还查不出来。改法：显式 `raise`，或者换稀疏计数键。
- **对原数组排序来代替签名**：`sorted(strs)` 得到 `["ate","bat","eat","nat","tan","tea"]`，同组的 `"ate"/"eat"/"tea"` 被 `"bat"` 隔开，按「相邻相等」合并会碎成三组。必须先算签名，再按签名排序（离线写法），或者在哈希表里按键入桶。
- **返回时写成 `list(buckets.keys())` 或忘了 `list()`**：哈希表里存的是桶（`list[str]`），答案要的是桶的内容，`keys()` 只能拿到签名；而 `return buckets.values()` 返回的是视图对象，LeetCode 的判题器按列表比较会挂，必须 `list(...)`。
- **空输入返回 `[[]]` 或 `[""]`**：`strs = []` 的正确答案是 `[]`。用 `list(buckets.values())` 天然返回 `[]`；手写 `if not strs: return [[]]` 就挂。空串 `""` 反倒合法，它自成一组。
