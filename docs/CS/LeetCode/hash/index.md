# 哈希 | Hash

!!! abstract "Hot 20 · 第 1 类"
    **什么时候想到它**：要把元素**分组 / 去重 / 计数 / 判断两个东西是否等价**，而且这种等价关系能写成某种「规范形」。
    **核心动作**：造一个只依赖等价类的键 → `dict[key].append(x)`，一次扫描结束。

## 套路

哈希题只有三步，难点全在第一步：

1. **造键**：找一个「同组必相同、异组必不同」的规范形。
2. **查表**：`dict.get(key)` / `set` 判断见没见过。
3. **入桶 / 更新**：分组就 append，计数就 +1，判重就标记。

常用键：

| 场景 | 键 | 建键代价 |
|:-----|:---|:---------|
| 字母异位词 | `"".join(sorted(w))` 或 26 维计数元组 | $O(k\log k)$ / $O(k)$ |
| 两数之和 | 反过来记「还差多少」：`target - x` | $O(1)$ |
| 子数组求和 | 前缀和的差值 `pre[j] - pre[i]` | $O(1)$ |
| 计数 / 众数 | 元素本身 | $O(1)$ |

同一题里键有多种选择时，比较的是**建键代价**和**会不会碰撞**：排序键最好写，计数键最快，质数乘积只是数学上好听。

## 易错点

- 键必须**无碰撞**：首字母、词长这类键都不行（`"ab"` 与 `"aa"` 同首字母、同长度，却不是异位词）。
- `list` 不可哈希，计数向量要转 `tuple`。
- 依赖「插入顺序」时是在吃 Python `dict` 保序的红利，换语言要自己维护。
