# 双指针 | Two Pointers

!!! abstract "Hot 20 · 第 2 类"
    **什么时候想到它**：数组里找配对 / 求某段区间，或者「答案由两端共同决定」；有序（或能排序）是关键前提。
    **核心动作**：两个指针往中间夹，每轮丢掉一个不可能的候选，把 $O(n^2)$ 压成 $O(n)$。

## 两种形态

- **左右夹逼（对撞）**：`left = 0, right = n-1`，比较两端后移动其中一侧。三数之和、接雨水、盛最多水的容器。
- **快慢指针**：一个探路一个跟随，用来找中点、判环、原地删除（这类题在本库里还没写）。

## 套路

1. 先问：数组有序吗？无序先排序，排序后「指针移动方向」才有单调性依据。
2. 每轮只移动**该移动的那一侧**，并当场结算这一侧：谁矮结算谁（接雨水）、和太大就右移（三数之和）、挡板矮就移它（盛水）。
3. 相遇 / 相等的收尾单独写清楚，防止多算或少算一格。

接雨水背后的严格理由不是「另一边有更高的柱子兜底」这种直觉，而是不变量：**`leftMax ≤ rightMax` 时，左侧水位由 `leftMax` 唯一确定**。

## 易错点

- 接雨水：**先更新该侧最大值，再累加** `max - height`；顺序反了遇到新高会加出负数。
- 三数之和：去重要在指针移动之后跳过重复值，否则漏解或重复解。
- 双指针的 $O(n)$ 依赖单调性，无序数组不能直接套。
