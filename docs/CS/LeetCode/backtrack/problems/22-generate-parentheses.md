# 22. 括号生成

!!! abstract "题单坐标"
    **Hot 20 · 第 9 类「回溯」** ｜ 难度：中等 ｜ 标签：`字符串` `动态规划` `回溯`

    一句话套路：只走合法分支——左括号还没用满就能加 `(`，已经写下的右括号少于左括号才能加 `)`。

## 题干

> [力扣 22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且**有效的**括号组合。

**示例 1**

```text
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2**

```text
输入：n = 1
输出：["()"]
```

**提示**

- `1 <= n <= 8`

## 思路

一个括号序列合法，当且仅当任意前缀里左括号不少于右括号，且整段长度是 `2n`、左右各 `n` 个。搜索时按这个条件剪枝，走到长度 `2n` 的叶子就都是答案，不用再做一次栈匹配。

状态只需两个数：已经用掉的左括号 `open_used`、已经用掉的右括号 `close_used`。

- `open_used < n`：可以再写一个 `(`。
- `close_used < open_used`：可以再写一个 `)`。右括号一旦超过左括号，后面无论怎么补都不合法。

做完选择就递归，返回后 `pop`，让同层的另一个选择从同一个前缀重新开始。

$n = 3$ 的搜索树（只画合法分支）：

```text
(
├─ (
│  ├─ (
│  │  └─ ) ) )          → ((()))
│  └─ )
│     ├─ ( ) )          → (()())
│     └─ ) ( )          → (())()
└─ )
   └─ (
      ├─ ( ) )          → ()(())
      └─ ) ( )          → ()()()
```

叶子数是第 $n$ 个卡特兰数 $\frac{1}{n+1}\binom{2n}{n}$。$n = 8$ 时是 1430，远小于不剪枝的 $2^{16}$。

**走一遍 `n = 2`。**

| 路径 | 下一步 | 原因 |
|:-----|:-------|:-----|
| 空 | `(` | 还没有左括号 |
| `(` | `(` 或 `)` | 左括号未满，右括号也不超过左括号 |
| `( (` | `)` | 左括号已经用满 |
| `( ( )` | `)` | 得到 `(())` |
| 回到 `(`，改走 `)` | `(` | 得到 `()`，再补一对得到 `()()` |

答案是 `["(())", "()()"]`。

## 代码（带注释）

> 按力扣提交格式写：一个 `Solution` 类。只用内置类型。

```python
class Solution:
    def generateParenthesis(self, n: int) -> list[str]:
        ans: list[str] = []
        path: list[str] = []

        def dfs(open_used: int, close_used: int) -> None:
            if len(path) == 2 * n:
                ans.append("".join(path))
                return
            if open_used < n:
                path.append("(")
                dfs(open_used + 1, close_used)
                path.pop()
            if close_used < open_used:
                path.append(")")
                dfs(open_used, close_used + 1)
                path.pop()

        dfs(0, 0)
        return ans
```

`"".join(path)` 在叶子处拷贝出一份字符串。如果把 `path` 列表本身放进 `ans`，后面的 `pop` 会把已收集的方案清空。

## 复杂度

| 写法 | 时间 | 空间 | 什么时候用 |
|:-----|:-----|:-----|:-----------|
| 剪枝回溯 | $O(C_n \cdot n)$ | $O(n)$ | 默认。$C_n$ 是卡特兰数，乘 $n$ 是拼字符串 |
| 先生成再过滤 | $O(2^{2n} \cdot n)$ | $O(n)$ | $n = 8$ 仍能跑，但剪枝理由讲不清 |
| 按卡特兰数递推拼字符串 | $O(C_n \cdot n)$ | $O(C_n \cdot n)$ | dp 版，面试不比回溯好写 |

递归深度最多 `2n`。$n \le 8$，剪枝回溯足够。

## 易错点

- **右括号的条件写成 `close_used < n`**：`)` 开头、`())(()` 这种序列都会被生成出来，还得再用栈滤一遍。
- **忘记 `pop`**：第二条分支接着第一条的尾巴长，`(())` 后面会拼出 `(()))`。
- **答案存的是列表引用**：函数返回前 `path` 已经空了，输出变成 `[[], [], ...]`。
- **左右数量用字符串 `count` 每次重算**：对，但每个节点都是 $O(n)$，没有必要；两个整数参数已经是这个状态。
